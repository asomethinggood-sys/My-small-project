CONTINUUM FOR WINDOWS 10 / 11 — x64

Extract the entire ZIP into one folder. Open Continuum.exe and accept Windows' administrator prompt. Click Connect. No configuration or additional runtime download is required.

Disconnect stops recovery. Closing the app disconnects; minimizing keeps it open. This is not a permanent kill switch. A connection check is a web request, not ping.

This release does not read older imported profiles or saved custom sources. Keep only one VPN connected at a time. The app is unsigned; Windows may show its normal unknown-publisher warning.

If a website still fails, disconnect and compare on your normal connection. Website restrictions on the service's exit address cannot always be fixed on your PC. Do not post your connection credentials when reporting a problem.
